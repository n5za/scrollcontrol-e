# Chrome Web Store Store Listing

## Extension Name
ScrollControl

## Short Description
Take control of your YouTube Shorts and Instagram Reels consumption with daily limits, time schedules, and usage tracking.

## Detailed Description
ScrollControl helps you take control of your short-form content consumption on YouTube Shorts and Instagram Reels.

**Set Daily Limits**
- Maximum Shorts/Reels per day per platform
- Maximum time spent per day per platform
- Automatic blocking when limits are reached

**Schedule Your Usage**
- Define allowed hours for short-form content
- Quick presets: Study Mode, Work Mode, Evening Only
- Custom schedules with day-specific windows

**Quick Actions**
- Pause tracking temporarily
- Block content immediately for 15min, 30min, 1h, or until tomorrow
- Override limits when you need to

**Track Your Usage**
- Real-time usage stats per platform
- Daily, weekly, and monthly breakdowns
- Hourly usage chart
- Session history with active time tracking

**Privacy First**
- 100% local — No data ever leaves your browser
- No analytics — Zero tracking, zero telemetry
- No accounts — No sign-up required
- Open source — Fully auditable codebase

## Privacy Practices
- Does not collect user data
- Does not transmit data to external servers
- Does not use analytics or tracking
- Uses Chrome storage API locally only

## Permissions Justification
- **storage**: Persist user settings and usage data locally
- **tabs**: Detect active tab for content script injection
- **scripting**: Inject content scripts into YouTube/Instagram pages
- **alarms**: Schedule daily reset and expiration checks
- **host_permissions (youtube.com, instagram.com)**: Detect and track short-form content on these platforms
